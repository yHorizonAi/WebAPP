BRAND COLORS
=============

Purpose:
These are three alternative visual themes for the same web application.
The app structure, components, UX, spacing, typography, interactions,
and functionality should remain consistent across all three versions.

Create 3 visual versions of the website:
- Version 1: Dreamy Purple / Coral / Navy
- Version 2: Coral / Orange / Teal
- Version 3: Soft Pastel / Lavender / Blush

IMPORTANT:
- Do not mix colors between themes unless explicitly instructed.
- Each version should use ONLY its assigned palette.
- Preserve strong contrast and readable text.
- Use the colors semantically rather than applying them randomly.
- Backgrounds should generally remain light and airy.
- Primary colors should be used for important actions and active states.
- Dark colors should be reserved for strong text, navigation, icons, or high-contrast elements.
- Gradients are allowed where appropriate, especially for decorative elements,
  cards, hero areas, backgrounds, and visual accents.
- The three versions should feel like the same product with different branding,
  NOT three completely different UI designs.

==================================================
GLOBAL DESIGN RULES
==================================================

The three themes must maintain the same:

- Layout
- Component hierarchy
- Navigation
- UX
- Interactions
- Animations
- Spacing
- Border radius
- Typography
- Information architecture
- Functionality

Only the visual branding should change.

Design direction:
- Modern
- Clean
- Soft
- Premium
- Friendly
- Minimal
- Smooth
- Slightly playful
- Strong visual polish
- Subtle gradients
- Soft rounded cards
- Smooth micro-interactions
- Avoid excessive visual noise
- Avoid excessive shadows
- Avoid overly saturated backgrounds
- Keep the interface easy to scan

Accessibility:
- Never sacrifice text readability for aesthetics.
- Use the dark palette color when stronger text contrast is required.
- Buttons and interactive elements should have clear hover/focus/active states.
- Do not place light text on light pastel backgrounds.

Implementation:
Create the color system using CSS variables/design tokens so the entire
theme can be switched without rewriting individual components.

Example:

:root {
  --color-primary: ...;
  --color-secondary: ...;
  --color-accent: ...;
  --color-surface: ...;
  --color-text: ...;
  --color-border: ...;
}

Create separate theme definitions for:
- theme-purple
- theme-coral
- theme-pastel

The application should be able to switch between the three themes easily.
