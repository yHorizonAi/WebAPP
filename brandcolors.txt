LYRA-STYLE BUDGET TRACKER — BRAND COLORS
=============================================
Purpose:
A warm, personal financial-control app for women ages 25–40.
The product should feel like "my private money space" rather than a bank dashboard.

CORE BRAND IDEA
---------------
Emotional feeling:
- Safe
- Calm
- Personal
- Capable
- Grown-up
- Soft without feeling childish
- Financially organized without feeling corporate

The visual language should communicate:
"I am in control of my money."
NOT:
"The bank is monitoring my money."

Avoid a traditional banking aesthetic:
- Avoid corporate navy + bright green combinations.
- Avoid excessive blue-on-white dashboards.
- Avoid hard black borders.
- Avoid aggressive red/green financial signals.
- Avoid glossy fintech gradients.
- Avoid overly saturated colors.
- Avoid making every element look like a financial instrument.
- Avoid excessive cards, separators, and dense tables.

Brand personality:
CALM + FEMININE + MODERN + TRUSTWORTHY + PERSONAL

1. #B69BD9
2. #9CB1E8

Chart rules:
- Do not use rainbow palettes.

BACKGROUND STRATEGY
-------------------

The interface should be approximately:

70% neutrals
20% brand/support colors
10% status/decorative accents

Large surfaces:
- Warm Cream
- White
- Midnight Navy
- Deep Navy

Medium surfaces:
- Soft Lavender tints
- Soft Blush
- Very subtle Periwinkle

Small accents:
- Warm Rose
- Sage
- Terracotta
- Dusty Plum

Never make the entire page lavender/pink.
The softness comes from restraint.


GRADIENTS
---------

Use gradients only for large decorative/hero moments.

Primary gradient:
#F4DCE8 -> #A98FD1

Cool gradient:
#F0EAF7 -> #8BA3DE

Dreamy gradient:
#F4DCE8 -> #EEF0FB -> #A98FD1

Dark ambient gradient:
#111827 -> #18233A -> #292540

Rules:
- Large, slow gradients only.
- No neon gradients.
- No intense glossy fintech gradients.
- No gradient on every card/button.


SHADOWS
-------

Light mode:
Use warm-neutral, very soft shadows.

Preferred visual:
- low opacity
- large blur
- low spread
- very subtle elevation

Dark mode:
Use almost no visible shadow.
Create hierarchy primarily through surface color and borders.

Never use:
- harsh black shadows
- huge floating-card shadows
- glossy reflections


BORDER RULES
------------

Default:
1px solid #E7E0E8 (light)
1px solid #2D3952 (dark)

Borders should be:
- quiet
- rounded
- low contrast
- supportive

Do not outline every element.
Use whitespace and surface contrast first.

ACCESSIBILITY
-------------

Target WCAG AA contrast for normal text whenever practical.

Important:
- Never use Soft Blush as text on white.
- Never use Soft Lavender as small text on white unless contrast is sufficient.
- For small text, use Dusty Plum or a darker neutral.
- Status colors must always have a readable text color and/or an icon.
- Never rely on color alone to communicate paid, overdue, warning, or success.
- Pair status colors with labels, icons, patterns, or state text.

Examples:
"Paid" + check icon + sage tint
"Due soon" + clock icon + warm amber tint
"Overdue" + alert icon + terracotta tint


VISUAL HIERARCHY
----------------

1. Neutral background
2. Important financial number
3. Primary action
4. Supporting information
5. Status
6. Decorative accent

The user should immediately understand:
- What money do I have?
- What needs attention?
- What can I do next?

Color must support hierarchy, not create noise.


FEMININE DIRECTION
------------------

The goal is mature femininity, not stereotypical pink UI.

Use:
- muted lavender
- dusty plum
- warm rose
- cream
- soft blush
- gentle periwinkle

Avoid:
- hot pink
- bubblegum pink
- excessive flowers/hearts
- childish pastel rainbow
- glitter effects
- candy-like UI

The design should feel appropriate for a 25–40-year-old adult woman who wants something beautiful, private, and useful.


"NOT A BANK APP" VISUAL RULES
-----------------------------

DO:
- Use warm cream backgrounds.
- Give the dashboard breathing room.
- Use rounded corners.
- Use soft tinted sections.
- Use human language.
- Highlight personal progress.
- Make numbers feel understandable.
- Make the app feel owned by the user.
- Use subtle visual delight.
- Use illustrations/sparkles/cloud-like decoration only as accents.

DO NOT:
- Build everything as tables.
- Use corporate blue as the main accent.
- Use hard-edged data grids everywhere.
- Use bright green for money.
- Use red everywhere.
- Use dense KPI-wall layouts.
- Make every section look like an enterprise analytics product.
- Overuse gradients.
- Overuse shadows.
- Use strong black outlines.


PERSONAL "SAFE SPACE" DIRECTION
-------------------------------

The emotional sequence should be:

ENTER APP
-> "This feels calm."

SEE MONEY
-> "I understand what's happening."

SEE TASKS / BILLS
-> "I know what needs attention."

TAKE ACTION
-> "That was easy."

LEAVE APP
-> "I have control."

The UI should never create:
- panic
- guilt
- urgency for no reason
- corporate pressure
- fear around money

Use color to reassure and organize, not to emotionally punish.


IMPLEMENTATION RULE
-------------------

When building the app, define semantic CSS variables first.

Example:

:root {
  --color-bg: #FBF8F5;
  --color-surface: #FFFFFF;
  --color-text: #302A35;
  --color-text-secondary: #706777;
  --color-border: #E7E0E8;

  --color-primary: #8D72B5;
  --color-primary-hover: #795DA2;
  --color-secondary: #8BA3DE;

  --color-lavender-soft: #F0EAF7;
  --color-blush: #F4DCE8;
  --color-rose: #D7A7BC;

  --color-success: #6F947C;
  --color-warning: #A98550;
  --color-danger: #A96868;
}

Dark mode should override the semantic variables rather than hardcoding new colors throughout components.

NEVER hardcode random hex colors inside individual components if an existing semantic token can be used.


COMPONENT CONSISTENCY RULE
--------------------------

One semantic meaning = one color family.

Examples:
- Primary action -> lavender
- Secondary action/info -> periwinkle
- Positive -> sage
- Warning -> warm amber
- Negative -> terracotta

Do not assign random colors to different tabs simply because they need to "look different."

Tabs may have different visual accents, but they must remain inside this brand palette.


DESIGNER'S ONE-SENTENCE TEST
----------------------------

Before adding a color, ask:

"Does this make the user's financial space feel calmer, more personal, and more understandable?"

If not, do not add the color.


FINAL BRAND DIRECTION
---------------------

The app should look like:
A beautiful private money journal + control center.

Not:
A bank.
Not:
An accounting spreadsheet.
Not:
An enterprise finance dashboard.
Not:
A childish pink budgeting app.

Core visual formula:
MIDNIGHT NAVY
+ WARM CREAM
+ SOFT LAVENDER
+ DUSTY PLUM
+ PERIWINKLE
+ MUTED ROSE
+ VERY RESTRAINED STATUS COLORS

Overall impression:
"Beautiful enough that I want to open it.
Calm enough that I am not scared of my finances.
Clear enough that I always know what to do next."
